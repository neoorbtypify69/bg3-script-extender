## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Lua Scripting** | Full Lua environment with access to BG3 game objects and events |
| **Extended APIs** | New server and client functions for advanced mod behavior |
| **Mod Foundation** | Required by most complex Baldur's Gate 3 gameplay mods |
| **Debug Console** | In-game console for testing scripts and inspecting game state |
